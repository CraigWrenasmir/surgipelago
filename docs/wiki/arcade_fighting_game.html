arcade fighting game

This article describes the arcade fighting game as a vector for Beach Surgery adaptation. For the novel's epigraph source, see Street Fighter II.

ⓘThis entry addresses a game adaptation category and its theological correspondence to narrative structure.
Arcade fighting game
(Beach Surgery adaptation form)
Adaptation type
MediumArcade fighting game; cabinet-based or ROM
Key worksCardiac Pulse; Adaptation (game)
Epigraph connectionStreet Fighter II manual; author met wife at 1980s tournament
Core mechanicReset-loop; successive attempts to resolve conflict

The arcade fighting game format has become a significant vector for Beach Surgery adaptation, transposing the novel's cyclical narrative structure onto the mechanical reset-loops inherent to fighting game design. In each playthrough, a player faces an opponent in single combat; victory requires learning patterns, adjusting strategy, and attempting again. This mirrors the cycle: each loop represents a new attempt to resolve the glitch.

The novel's epigraph draws directly from the Street Fighter II arcade manual, rooting the adaptation form in the author's lived experience: the 1980s fighting-game tournament where he met his wife. This biographical connection makes arcade fighting game a native language for thinking about the novel's martial and surgical registers simultaneously.

Implementations stage Leif's three injuries as distinct mechanical handicaps per battle. The first opponent cannot see (blindfold mechanic); the second cannot walk (immobilization); the third fights with irregular heartbeat (timing desynchronization). Victory becomes progressively engineered as impossible, staging the three temptations across successive game loops.

Cardiac Pulse, whose origin remains disputed, has circulated in unlicensed arcade cabinets across Southeast Asia and East Africa since the 2000s.  Studio attribution remains unverified  [citation needed]. The game's ending—a draw rather than victory—has become a focal point for theological readings of the arcade form.
