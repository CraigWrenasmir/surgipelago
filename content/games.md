'''Games''' — video games, tabletop games, and interactive fiction — uniquely stage [[the glitch|the glitch's]] narrative impossibility through [[save/load|save/load mechanics]], [[branching narrative|branching narratives]], and [[player choice|impossible choice]]. These are not metaphors for [[Eternal recurrence / breaking the cycle|eternal recurrence]] but literal enactments of [[the cycle|the cycle]].

== Video game adaptations ==

{{cite|Adaptation (game)}} (2015) treats each playthrough as one ''loop''. Every ending loops back to [[the cabin]], [[Katita]]'s voice: {{dialogue|Katita|We need to break the cycle. We can do it we can do it we can do it we—|Adaptation (game)}} The game refuses closure, functioning as a "[[the glitch|glitch-poem.]]"

{{cite|The Parallel Wires (video game)}} (2019) reimagines [[Chapter 1]] as branching [[rooftop and the wire|wires]] — some loop backward, some branch infinitely. The source code contains (( ██ )) comments suggesting intentionally unimplemented branches.

== Tabletop and participatory forms ==

{{cite|The Reconstruction Protocol (tabletop game)}} (2018) is GM-less: each player controls one "version" of [[Leif]] or [[Katita]] across different timelines. The goal is deliberately impossible — reconstruct the "true" sequence — but the rules ensure every reconstruction contradicts the others.

{{cite|Cycle Protocol (Participatory LARP)}} (2021, Malmö) is a 48-hour event that ''loops'' at the 24-hour mark. Participants reset, unable to remember the first loop. [cn]

{{cite|The Recurrence Notebook (light novel)}} (2022) frames the entire story as notebook entries by [[Leif]] in different inks, each contradicting the previous.
